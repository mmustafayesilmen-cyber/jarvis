# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Jarvis: a Turkish-first (with English mode), local voice assistant for Windows. Code comments, user-facing strings, and many identifiers are Turkish; assistant replies address the user as "efendim"/"sir". There is no test suite, linter, or build step, and no README.

## Running

- First-time setup: `install.bat` (creates `.venv`, installs `requirements.txt`, downloads Piper voices into `voices/`).
- Run: `jarvis.bat` (starts `ollama serve` and `python main.py` in the venv), or `Jarvis.vbs` for a console-less launch via `pythonw`. Ollama must be installed; the LLM is `qwen3:8b` (`brain.py: MODEL`).
- Under `pythonw`, `main.py` redirects stdout/stderr to `jarvis.log` (rotated at 5 MB). Debug by reading that log — `print(..., flush=True)` and tracebacks land there.
- `_patch_fix*.py` are throwaway one-off patch scripts (string-replace edits to other files), not part of the app.

## Architecture

**Process model.** `main.py` (~1700 lines) is the hub: a FastAPI/uvicorn server bound to `127.0.0.1:8765`, a pywebview HUD window + pystray tray icon, and the voice loop `run_assistant()` on background threads. The UI talks to Python over a single `/ws` WebSocket; every connection must present the per-launch random `TOKEN` and the `ALLOWED_ORIGIN` (so other sites can't connect). Python pushes state to the UI with `emit(type=..., ...)`; the phone can also connect as a second client and receives synthesized audio when `len(clients) > 1`.

**Command pipeline** (`think()` inside `run_assistant`), in priority order for each utterance:
1. Mode dispatch — if a full-screen mode is open (`scene_state`, `ill_state`, `hero_state`), normal Jarvis stops listening and the utterance goes only to that mode's handler (`scene_dispatch`, `ill_dispatch`, `hero_dispatch`).
2. `router.route()` (Turkish) / `router.route_en()` — regex/rule-based fast path for common commands (volume, time, timers, routines, music, home control, etc.). Returns a spoken reply string or `None`. `router.route` delegates to `route_tr_extra`, `extras.route`, and `route_routine` first. `router.snap`/`known_commands` do fuzzy command correction (rapidfuzz) for speech-recognition errors.
3. `brain.Brain.ask_stream()` — fallback to the local LLM (Ollama). gemma/qwen via Ollama lack native tool calling, so the model emits a one-line JSON `{"tool": ..., "args": {...}}`; the result is fed back as `[ARAÇ SONUCU]`. Tools are plain functions in `tools.py`, registered in the `TOOLS` list at the bottom (`BY_NAME` is derived); the system prompt in `brain.py` is built from their signatures and first docstring lines, so **a new tool needs a one-line docstring and an entry in `TOOLS`**. `CTX` must stay constant across calls or Ollama reloads the model.

**Voice** (`voice.py`): wake word via openwakeword, faster-whisper STT (CUDA DLLs added at runtime), TTS via edge-tts (default) or local Piper (`config.json: tts`), optional "Jarvis FX" post-processing. `voice.is_private` is set so that in modes the spoken text/audio clips are not logged or saved (`cmdbuf.py` holds commands only in RAM while processing).

**Scene modes** (`scenes*.py` + `ui/scene_*.html`): full-screen pywebview windows (Ortam, Uzay, Müzik, labs for kimya/biyoloji/fizik/matematik/astronomi/jeoloji, notlar, yuvam, hologram, rapor, sistem, ders, pomodoro, kartlar, gelisim, plus separate illusion/hero/code modes). Pattern:
- `scenes.py` defines `KINDS`, and per-kind `HANDLERS`, `INITS`, `TITLES`, `EXIT_SAY`; further modules (`scenes_lab.py`, `scenes_sci.py`, …) register themselves into those dicts at the bottom of `scenes.py`. `scenes.handle(kind, text, state)` returns a dict (`say`, `do`, `exit`, …) or `None`.
- `main.open_scene`/`close_scene`/`scene_dispatch` create the window (`/scene/{kind}?t=TOKEN`), and route handler results to the page via `emit(type="scene_do", kind=..., do=...)`. Some kinds have special-cased branches in `scene_dispatch` and `open_scene` (muzik, pomodoro, kartlar/gelisim, ders, sistem).
- Adding a mode touches: `scenes.KINDS`/dicts, a `ui/scene_<kind>.html` (the `/scene/{kind}` route maps lab/sci kinds to shared `scene_lab.html`/`scene_sci.html`), `scene_kit.py` (`SECTION` map for command palette help), and the example commands in `ui/guide.html` (read at request time by `scene_kit.help_for`). Shared UI kit is `ui/scene_kit.css|js`, served via `/kit/{name}`.
- Domain data lives in `*_data.py` / `lab_concepts.py`; mode backends such as `ders_srv.py`, `pomodoro.py`, `reports.py` are separate modules.

**State & config.** User settings: `settings.py` over `config.json` (defaults in `settings.DEFAULTS`). Persistent data is flat JSON files in the repo root (`memory.json`, `reminders.json`, `routines.json`, `notes.json`, `agenda.json`, `ders.json`, `pomodoro.json`, `raporlar.json`); several are gitignored. `workspace/` (gitignored) is the sandbox for generated code projects (`codeproj.py`, `/code` editor).

**Integrations** (Windows-specific: pywinauto, pycaw, winsdk, pyautogui): WhatsApp Web watcher/sender (`whatsapp.py`, profile in gitignored `wa_profile/`; sending requires an explicit spoken confirmation tracked via `tools.set_user_turn`), Phone Link control (`phone.py`), Google Home through an Edge window (`tools.home_control`), a fan on an Arduino/PlatformIO board (`fan.py`, `arduino/fan_pio`), media keys and now-playing (`nowplaying.py`, `loopback.py` audio tap for the music visualizer).

**MEBİ takibi** (`mebi.py`, `extras.route_mebi`, `main.open_mebi`/`mebi_cmd`, `tools.MEBI_HOOK`): MEBİ (mebi.eba.gov.tr, MEB'in öğrenme platformu) normal, tam ekran olmayan bir pywebview penceresinde açılır; Jarvis dinlemeye devam eder. Öğrenci girişi kendisi yapar, şifre hiçbir yerde okunmaz/saklanmaz; oturum `mebi_profile/` (WebView2 profili, `webview.start(private_mode=False, storage_path=...)`, tüm pencerelerle paylaşılır) içinde kalır. İzleme pasiftir: `Tracker` 5 sn'de bir `evaluate_js(POLL_JS)` ile sayfayı okur (sayfaya köprü/`js_api` açılmaz, tıklama yapılmaz). MEBİ içerik sayfaları `#mainFrame` aynı-alan iframe'indedir; POLL_JS orada XHR POST'larını (`save-video`, `save-summary`, etkinlik kaydı, `get-student-subject` bayrakları) ve video durumunu dinler. Sonuç `mebi.json`'a yazılır (gitignored). MEBİ konu adresleri: `/student/section/subject-details/{GUID}` (konu), `/student/interactive-quiz/{aynı GUID}` (değerlendirme soruları). Sayfa yapısı değişirse `POLL_JS` ve `PAGE` regex'i güncellenmelidir. Etkinlik tamamlama `POST /student/section/save-skill-based-app` (gövde `{"SkillBasedAppId": guid}`) ile doğrulandı; diğer etkinlik türleri (`showSubjectApp`, `showContextualApp`, `show3bApp`) `_apply_event` içinde `save|score|complet` ile yakalanır ama görülmedi. `update-viewing-time` etkinlik açıkken de 30 sn'de bir gider, bu yüzden süre tek başına "izledi" kanıtı sayılmaz; `get-student-subject` yanıtı (`video`/`summary`/`podcast` bayrakları, `viewingTime`) sunucu gerçeğidir. MEBİ'nin özet PDF'leri (`ogm-large-cdn.eba.gov.tr/mebi/pdf/*.pdf`) doğrudan istenince 403 verir; erişim kontrolü aşılmaz.

Sayfa komutları sesli komutla aynı yoldan gider (`{type:"text"}`). `mola_cmd(action, dakika)`: `open` (modu açar), `start` (açar ve başlatır), `default`, `timer` (modsuz, tam ekran zamanlayıcıda label `MOLA`). `timer.html` altındaki MOLAYA GEÇ düğmeleri `timer_break` mesajı yollar (`timer_to_break`). Pomodoro açıkken `mola ver` pomodoro evresini atlar (mola modu değil).

**Masaüstüne geç:** `mode_peek` WebSocket mesajı sayfadan bağımsızdır ve başlığı `JARVIS ` ile başlayan tüm pencereleri küçültür (`peek_desktop`, Ctrl+Alt+M ile aynı). **Jarvis tarayıcısı** (`jbrowser.py` ana süreç tarafı, `jbrowser_proc.py` ayrı süreç; "YouTube aç" vb. burada açılır, VPN proxy'si yalnızca bu pencereye uygulanır, `extras.route_browser`): ayrı süreç olmasının nedeni WebView2 proxy ayarının süreç başına tek olmasıdır. Ana süreç stdin'den satır başına JSON komutu yollar (`goto/back/forward/reload/fullscreen/scroll/badge/close`). Her sayfa yüklenince `jbrowser_proc.BAR_JS` enjekte edilir: fareyi üst kenara götürünce çıkan geri/ileri/yenile/ana sayfa düğmeleri ve adres kutusu (kapalı shadow DOM, stil CSSOM ile; köprü yok, düğmeler yalnızca `history`/`location` kullanır). Sekmeler aynı pencerede: `jbrowser_proc.main` pencerenin WinForms `Form`'una kendi sekme şeridini ekler, her sekme aynı `CreationProperties` ile ayrı bir `WebView2`dir (aynı profil/proxy); ilk sekme pywebview'in kendi denetimidir ve yok edilmez, yalnızca gizlenir. Sayfadaki `＋`/Ctrl+T/Ctrl+W/Ctrl+Tab/Ctrl+tık `window.__jv` bayrağını bırakır, süreç 0,4 sn'de bir yoklar; `target=_blank`/`window.open` pywebview'in `on_new_window_request`'i değiştirilerek yeni sekme olur (varsayılan tarayıcıya atılmaz). Sesle: "yeni sekme aç", "sekmeyi kapat", "sonraki/önceki sekme". Telefon tarayıcısı (CDP) tek bir sayfa hedefine bağlanır, sekmeler arasında geçiş yapmaz. Sesle geri/ileri/yenile/ana sayfa `extras._browser_nav` içindedir: Jarvis tarayıcısı ve/veya MEBİ penceresi açıksa en öndekine (`_front_title`) uygulanır; MEBİ için `mebi_cmd("nav_*")` içeriği `#mainFrame` iframe'inde yönetir.

**Telefona ekran yansıtma** (`mirror.py`, `/mirror` + `/mws` uçları `main.py` içinde, `ui/mirror.html`, `phone.connect(mirror=True)`, `extras.route_mirror`): telefon sayfası yalnızca mevcut USB tüneli üzerinden (`phone.py`: `adb reverse tcp:8765`) açılır; sunucu hâlâ yalnızca 127.0.0.1'i dinler ve `/mws` de `/ws` ile aynı kapıyı kullanır (doğru `Origin` + her açılışta değişen `TOKEN`, `secrets.compare_digest`). Telefon sayfası iki WebSocket açar: `/ws` (komut, Jarvis mesajları, ses) ve `/mws` (ikili JPEG kareleri; başlık `<IHH`: kare no, imleç x/y 0-65535). Düşük gecikme: aynı anda en çok 1 kare yoldadır, telefon `{"a": no}` ile onaylayınca o an yeni kare yakalanır (kuyruk birikmez), değişmeyen kare atlanır, gidiş-dönüş 140 ms'yi aşarsa kalite/boyut düşer. Yakalama `ImageGrab` yerine GDI `StretchBlt` ile doğrudan küçültülmüş alınır (~33 ms; `ImageGrab`+yeniden boyutlandırma ~65 ms). Başlama/bitiş `mirror.state["on_change"]` ile HUD'a ve tepsi bildirimine gider (sessiz yayın yok); `mirror.kick()` hepsini keser. Yalnızca izleme: telefondan fare/klavye kontrolü yoktur. Not: testlerde gerçek yönlendirme çağrılırsa `lock_screen`/`monitor_off` gerçekten çalışır (`threading.Timer`); testte `JARVIS_POWER_DRYRUN=1` kullanın ve yalnızca kendi yönlendirmenizi çağırın.

**Kablosuz (Wi-Fi) yansıtma** (`lan.py`, `mirror.serve(lan=True)`, `ui/mirror.html` aynı sayfa `jv-lan` işaretiyle, `extras.route_mirror` kablosuz komutları): USB'siz, aracısız doğrudan bağlantı. Asıl Jarvis sunucusu hâlâ yalnızca 127.0.0.1'dedir; ağa açılan tek şey `lan.py` içindeki AYRI küçük FastAPI uygulamasıdır (0.0.0.0:8766), yalnızca sesle `lan.start()` çağrılınca açılır, `lan.stop()` portu kapatır, her Jarvis açılışında KAPALIDIR (kalıcı değildir). Yalnızca `/` (sayfa), `/pair/start`, `/pair/confirm`, `/ws` (yazılı komut, mic_toggle, open_guide), `/mws` (yayın) sunar; `Guard` ASGI katmanı sunucu kapalıysa ya da istemci RFC1918/bağlantı-yerel/geri döngü dışındaysa (`private_client`, açık izin listesi; Python'un `is_private`'ı belgeleme aralıklarını da kabul ettiği için kullanılmaz) hiçbir şey sunmaz. Eşleştirme: 6 haneli kod yalnızca bilgisayarda gösterilir (`HOOKS["pair_code"]`: HUD + bildirim), 120 sn, 5 hatalı denemede 60 sn kilit; cihaz anahtarının yalnızca SHA-256 özeti `lan_devices.json`'da (gitignored) durur, en çok 2 cihaz. Her istek same-origin olmalı (`Origin == http://<Host>`). Ana arayüzdeki mesajlar `main.emit` → `lan.broadcast` ile yalnızca izinli türlerde (`FORWARD_TYPES`) telefona iletilir. Trafik düz HTTP: yalnızca güvenilir ev ağı. İlk açılışta Windows güvenlik duvarı sorar (özel ağlar).
Uzaktan erişim için Tailscale desteği: `lan.tailscale_ip()` (psutil ile "tailscale" adlı arayüzün 100.64.0.0/10 adresi) ve `private_client(host, server_ip)`: 100.64.0.0/10 istemcisi YALNIZCA bağlantı bilgisayarın kendi Tailscale adresine (`scope["server"]`) geldiyse kabul edilir; bu aralık başka ağlarda (operatör/yurt) da kullanılabildiği için genel olarak açılmaz. Siteyi herkese açık yapan bir yol (Netlify/genel tünel) bilerek YOKTUR: ekran + komut yüzeyi internete açılmaz.

**Elektronik Laboratuvarı** (`elektronik_data.py`, `elektronik_analiz.py`, `scenes_elektronik.py`, `ui/scene_elektronik.html`, kind `elektronik`, `/vendor/three/three.min.js` main.py'de, `extras._yeni_kind`, `ui/remote_pc.html` GROUPS): 3B ortamda (three.js, `modes.js`) kullanıcının kendi devre kartını (PCB) tasarladığı mod; sahne kalıbıyla `scenes.py` sonunda kayıtlı, çıkış yalnızca açık ifadelerle, uzaktan whitelist'te DEĞİL. Sayfa parça geometrisini/yerleşimini (x, z, r) ve tel çizimini yönetir; Python parça bilgisini, çözümlemeyi ve komutları. Sözleşme: `scene_init` verisi `{parts:{id:{ad,kat,ref,kisa,bilgi,pinler:[{ad,tip,acik}],ozellik,kullanim,dikkat,degerler?,varsayilan?,renkler?,satir?,m?}}, kats, kart, kartlar, sablonlar}`; kart `{ad,w,h,renk,parcalar:[{i,p,x,z,r,deger?,renk?,etiket}],teller:[{a:[i,pin],b:[i,pin],tip}]}` (w/h 2,54 mm ızgara birimi). Sayfa → Python (hepsi `{type:"text"}`): `§kart|<json>` (her değişiklikte, sessiz; adı varsa `elektronik_kartlar.json`'a otomatik kayıt), `§ac|ad`, `§silkart|ad`, `§sablon|id`, `§bilgi|parça` ve düğmelerin söylediği Türkçe komutlar. Python → sayfa `do.op`: `ekle sil kart ad boyut renk bagla bilgi gorunum kontrol sim simdur kod bom hesap anlat kartlar` (`do.msg` alt satırda görünür). Parça id'leri SABİTTİR (3B modeller bunlara göre çizilir); pin SIRASI modeli belirler (2 bacaklı kutuplu parçada [0]=artı/anot; DIP'te gerçek numara sırası; kartlarda `satir:[n1,n2]`). `elektronik_analiz.Devre` teller→düğüm (union-find) kurar; `SEM` (elektronik_data) yalnızca çözümleme içindir (kaynak/besleme aralığı/iletim kenarları/yükler/koşullu anahtarlar/sürücüler, sayfaya gitmez). Kontrol, simülasyon ve kod üretimi KURAL TABANLI ve yaklaşıktır (gerçek devre benzetimi değil): kısa devre, dirençsiz LED, besleme aşımı (3,3 V parçaya 5 V), ters kutup, boşta bacak, pull-up, MCU'ya doğrudan motor/röle, pin akımı, I2C eşleşmesi, ortak toprak. Kod `workspace/elektronik/<kart>/<kart>.ino` olarak kaydedilir. Yeni parça: `PARTS`'a `P(...)`, gerekirse `SEM` ve `ALIAS`; yeni şablon `SABLONLAR`'a (`python -c` ile kontrol 0 hata vermeli). `extras._yeni_kind` "X devresini kur" cümlesini şablon varsa modu açıp `scenes_elektronik.PENDING` ile kurar. **Blok tabanlı kart kurucu** (`elektronik_bloklar.py`, sayfada KUR sekmesi, `scenes_elektronik._blok_komut/_tarif_isle/NOTIFY/SAY`, `extras._yeni_kind` + `PENDING`): kullanıcı özelliği söyler ("kart kur: uno ile sıcaklığı ölçüp ekranda gösteren, 30 derecede fanı açan ve alarm çalan kart"); yerel LLM (`brain.MODEL`, `format=json`, `brain.CTX` değişmez) YALNIZCA blok id'si + parametre seçer, kablolamayı/pin/direnç/güç/kodu blok kuralları deterministik yapar. `sec()` modelin çıktısını doğrular (katalogda olmayan id atılır, parametre sınırlanır, tarifte karşılığı olmayan blok atılır, kuralın bulduğu eksik blok eklenir, tarifte açık yazılan parametre modelinkinin önüne geçer); Ollama yoksa/geçersizse `sec_kural` (katlanmış ASCII + eş anlamlı regex) tek başına çalışır. Katalogda olmayan istek (`_YOK`: GPS, Wi-Fi, RFID, RTC...) uydurulmaz, `notlar`a "X için bloğum yok, en yakın: Y" yazılır. "30 derecede" gibi sayısal koşul `kart["ipucu"]` (`{esik, olcu: temp|cm|hum, yon}`; `_clean` korur, sayfa düşürürse `E["ipucu"]` yedeği) olarak `elektronik_analiz.Kod` içinde `ESIK_*` sabiti + buzzer/röle/motor koşulu olur. `Ctx` (kurucu bağlamı): `pin(tur, ne)` tür = dijital|giris|pwm|analog|kesme (en az yetenekli boş pin önce; I2C/SPI sabit pinleri bloklar çalışmadan rezerve edilir, D0/D1 ve ESP32 G1/G3/G12 kullanılmaz), `hat5/hat33/gnd` (3,3 V kartlarda 5 V = VIN/VBUS), `i2c(parça, ihtiyaç)` (mantık gerilimi uyuşmazsa `seviye_donusturucu` ekler), `pil(tur)` (ortak harici pil, eksisi MCU GND'sine), `akim()` bütçesi. `kur(plan, mcu, ipucu, esnek)` → `{kart, notlar, mcu}`: kart `Devre.kontrol()`'den geçer, hata/uyarı `notlar`a eklenir; Uno/Nano'da (kullanıcı seçmediyse) pin yetmezse Mega, NodeMCU/Pico'da ESP32 denenir. Sayfa ↔ Python: `kart kur: <tarif>`, `§blok|id|json`, `§blokcikar|i` (i = plan dizisindeki 0 tabanlı sıra), `§plantemizle`, `§mcu|id`, `§kur`; `do.op` `plan` (`{mcu, plan:[{i,id,ad,ozet}], notlar, calisiyor}`), kurulunca `kart` + bir kez `anlat`. Plan yalnızca RAM'dedir (`E["plan"]`, her açılışta `init_payload` sıfırlar), tarif diske yazılmaz. **Yeni blok eklemek**: `elektronik_bloklar.py` içinde `@_blok(id, ad, kat, acik, parcalar, {pin ihtiyacı}, [param], kw_regex, kisa)` ile `uret(c, p)` yazın: parçayı `c.add(pid)`, teli `c.tel(a, pin, b, pin)`, MCU pinini `c.pin(...)`, gücü `c.hat5/hat33/gnd` ile bağlayın (pin adları `PARTS`'taki gerçek adlar olmalı, yanlışsa `BlokHata`); LED direnci `_r_led`; kodu gereken parçanın `Kod.g_<parça>` üreticisi `elektronik_analiz.py`'de olmalı. Sonra `python -c "import elektronik_bloklar as b; print(b.dogrula())"` boş dönmeli, bloğu her MCU ile tek başına ve rastgele kombinasyonlarda kurup `Devre(kart).kontrol()` 0 "hata" vermeli (`_YOK` tablosuna karşılığı olmayan istekleri, `_MCU_KW`'ye kart adlarını ekleyin). `Devre._devices` artık toprak/besleme hattına geçmez (bölücü/pull-up dirençleri başka parçaları pine bağlamasın); pol denetimi besleme hattının ötesine yürümez (motor yanındaki geri tepme diyotu yanlış 'ters kutup' vermesin); PIR çıkışı 3,3 V sayılır (`SEM['pir']['o33']`).
